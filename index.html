Hướng dẫn đưa lên GitHub Pages

Ứng dụng này đã được cấu hình tối ưu để chạy hoàn toàn miễn phí trên GitHub Pages. Bạn chỉ cần thực hiện các bước sau:

  1. Tạo một Repository mới trên tài khoản GitHub của bạn (ví dụ: logi-intern-hcmc).
  2. Tạo file tên index.html và dán toàn bộ mã nguồn này vào.
  3. Vào mục Settings -> Pages -> phần Build and deployment chọn branch main và nhấn Save.
Đã sao chép thành công!
